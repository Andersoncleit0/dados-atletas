# 🏅 Dados dos Atletas

Projeto em JavaScript que recebe informações de atletas e realiza cálculos como **categoria, IMC e média válida das notas**, simulando um sistema de avaliação esportiva.

---

## 🚀 Funcionalidades

O sistema calcula automaticamente:

- 📊 Categoria do atleta
- ⚖️ IMC (Índice de Massa Corporal)
- 🧮 Média válida das notas (descartando maior e menor nota)
- 📋 Exibição completa dos dados do atleta

---

## 📌 Regras do projeto

### 🏆 Categorias por idade:
- Infantil: 9 a 11 anos  
- Juvenil: 12 e 13 anos  
- Intermediário: 14 e 15 anos  
- Adulto: 16 a 30 anos  
- Sem categoria: demais idades
